# Better Conversions
<img width="676.5" height="388.5" alt="better_conversions_example" src="https://github.com/user-attachments/assets/594888df-449a-41c5-9525-80eed052187f" />


A simple chrome extension that allows you to select a number and then from a context menu pick which new unit (based on an object) that you want to convert it into. 

## Features
- Transform a number into one of four unique units (bananas/two-story building for length and (average) adult man/elephant for weight).
- Swap between units that are used for the same purpose (for instance, swap between units that are both used for measuring length).
